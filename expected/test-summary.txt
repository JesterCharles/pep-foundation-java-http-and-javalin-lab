Expected output when every task is complete

Test command, run in starter/:
  mvn -q -o test

Terminal: no output, and the command exits with status 0.
Quiet mode (-q) prints only problems, so silence means every test passed.
The route tests start the app on a free localhost port and stop it again;
nothing listens after the run.

Test report, starter/target/surefire-reports/deskapi.DeskApiTest.txt, begins:
  Tests run: 5, Failures: 0, Errors: 0, Skipped: 0

Trying the running API by hand: start DeskApi from the IDE (run the main
method of deskapi.DeskApi) or with mvn -q -o compile exec:java in starter/;
it starts on port 7070 with one sample ticket. Then, in a macOS or Linux
terminal or in Command Prompt on Windows:
  curl -i http://localhost:7070/tickets
answers HTTP/1.1 200 with a JSON array holding the Printer jam ticket:
  [{"id":"T-1","title":"Printer jam","open":true}]
  curl -i http://localhost:7070/tickets/T-9
answers HTTP/1.1 404 with:
  {"error":"no ticket T-9"}
  curl -i -X POST -H "Content-Type: application/json" -d "{\"title\":\"VPN drops\"}" http://localhost:7070/tickets
answers HTTP/1.1 201 with:
  {"id":"T-2","title":"VPN drops","open":true}
  curl -i http://localhost:7070/ping
answers HTTP/1.1 200 with:
  {"status":"ok"}
Stop a terminal run with Ctrl+C in that terminal, and an IDE run with the
IDE's Stop button.
