# HTTP and Javalin — Code lab

Put the help desk on the network as a small Javalin JSON API: a repository behind an interface, a service with the rules, lambda route handlers, and honest 404/400 errors.

- **Edit:** the classes in `src/main/java/exercise/` named in the checklist. Each task is marked `TODO`.
- **Run the tests:** **Run Tests** in Exa Studio, or `mvn test` with JDK 17 and Maven. All 5 visible tests fail at first; every message starts with `Task N:`.
- **Done** when every visible test passes. **Submit** also runs held-out tests you can't see.

Full task steps and hints: `README.md` in the project folder.
